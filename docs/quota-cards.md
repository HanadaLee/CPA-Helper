# 每日 / 每周额度与额度卡

## 扣费与周期

- 每日额度于北京时间次日 00:00 重置；每周额度于北京时间下周一 00:00 重置。
- 每日、每周及所有生效中的额度卡统一按到期时间升序抵扣，永久额度卡最后抵扣。同一到期时间先每日、再每周、再按额度卡 ID。
- 额度卡发放即生效，无需兑换。失效、过期或已用完的额度卡不参与抵扣。
- 保留“不限制余额”开关：开启后不扣每日、每周或额度卡。
- 余额用尽后暂停 API 密钥；发放卡片、重置额度或进入新周期后自动恢复。手动禁用的密钥不会自动恢复。
- 后台每 15 秒检查到期、周期切换与密钥同步失败重试；扣费或管理操作后也会立即同步。实际请求限制仍依赖采集和上游密钥同步，并非请求前预授权。超出全部余额的请求差额会记录为“未覆盖”，不会伪造负余额。

## 管理与查询

- 用户管理：单人或批量发放、编辑、吊销额度卡/重置卡，重置单人、所选用户或全站用户的每日/每周额度。
- 我的配额：查看余额、额度卡状态、每次扣款的来源和重置记录。
- 状态：生效中、已用完、已过期、已失效（管理员吊销）。
- 重置卡由用户手动使用，每张只能使用一次；清零每日/每周已用额度，不改变下次周期重置时间，不改变额度卡余额。
- 历史扣款和重置记录保留。明细保留期清理不会删除额度卡扣款流水。

## 升级迁移

升级前备份数据库。迁移 `202609260001` 将每位用户的剩余每月额度转换为独立额度卡，有效期为迁移时刻起一个自然月（月末日期向当月最后一天收敛）；不限时余额转换为永久额度卡。余额为零的不发放。旧字段仅保留用于历史记录，不再作为可配置或可扣费额度。

新用户默认配额只保留每日、每周（默认均为 0）及原有不限制余额开关。原默认每月/不限时配置不再应用于新用户；已有用户余额由上述迁移保留。

额度卡后续可能已被扣费、编辑或吊销，不能安全逆向还原旧余额，因此此迁移禁止直接 Down；若需降级，应恢复升级前数据库备份。
